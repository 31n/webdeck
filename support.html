よくある質問

Web アプリを追加するには？

一覧の右上の「＋」から URL を追加します。Safari などの共有ボタンから Webdeck を選んでも追加できます。

AI が作った HTML を開くには？

「＋」→「HTML を貼り付け」または「HTML ファイルを取り込む」から追加します。AI のアプリの共有ボタンから Webdeck に送ることもできます。

開いているアプリを一覧に戻すには？

iPhone を振るか、ページの一番上から下に引っ張って待つと、画面の下のバーに最小化されます。バーをタップするか、上に引っ張ると戻ります。操作の割り当ては、一覧の右上の歯車（設定）で変えられます。

オフラインで使えますか？ 通知は届きますか？

本アプリはオンラインでの利用を前提にしています。Web アプリのオフライン動作（Service Worker）と Web プッシュ通知には対応していません。通知が必要な Web アプリは、Safari からホーム画面に追加してお使いください。

ログイン状態を消したい

アプリを長押しして「編集・共有」→「サイトデータを消去」を選ぶと、そのアプリの Cookie や保存データが消えます。

画面が PC 向けの小さな表示になる

「編集・共有」の「スマホの幅で表示」をオンにすると、画面幅の指定がないページをスマホの幅に合わせて表示します。
