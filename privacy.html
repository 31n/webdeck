プライバシーポリシー

トップ サポート プライバシーポリシー

制定日: 2026 年 10 月 29 日

Webdeck（以下「本アプリ」）は、利用者の個人情報を開発者が集めることはありません。本アプリでのデータの扱いを以下に説明します。

1. 開発者が集める情報

ありません。本アプリには、利用状況の分析、広告、トラッキングの仕組みは入っていません。開発者のサーバーにデータを送ることもありません。

2. 端末の中に保存する情報

  • 登録した Web アプリの URL・名前・アイコン、取り込んだ HTML、フォルダ、設定は、利用者の端末の中だけに保存します。
  • Web アプリごとの Cookie やストレージ（ログイン状態など）も、端末の中に Web アプリごとに分けて保存します。
  • これらは、本アプリを削除するか、本アプリの「サイトデータを消去」「削除」で消せます。

3. Web アプリとの通信

  • 本アプリで開いた Web アプリやサイトには、利用者の端末から直接接続します。そのサイトでの情報の扱いは、各サイトのプライバシーポリシーに従います。
  • Web アプリを追加したとき、名前とアイコンを表示するために、そのサイトの情報（manifest やアイコンの画像）を取得します。

4. 端末の機能の利用

本アプリで開いた Web アプリが、カメラ・マイク・位置情報・写真への保存を求めた場合に限り、iOS の許可の確認を経て利用します。得られた情報は、その Web アプリに渡されるだけで、開発者に送られることはありません。許可は iOS の「設定」アプリからいつでも変えられます。

5. 共有シート

ほかのアプリの共有ボタンから本アプリに送った HTML や URL は、端末の中に一時的に置き、本アプリを開いたときに一覧に取り込みます。外部には送りません。

6. アプリ内課金（チップ）

チップの購入は Apple の App Store が処理します。開発者が利用者の氏名や支払い情報を受け取ることはありません。

7. お子さまの利用

本アプリは、お子さまの個人情報を意図して集めることはありません。

8. このポリシーの変更

内容を変更する場合は、このページでお知らせします。

9. お問い合わせ

サポートのページをご覧ください。
